# 染钟楼谜团 单选题生成模板

## 使用说明

请将以下 Prompt 复制给 AI，提供对应的规则/角色文档片段，让它生成单选题。

---

## Prompt

你是一名《染·钟楼谜团》（Onetown Murder Mystery）的说书人认证考试出题专家。请基于以下规则/角色文档，生成 **10 道高质量的单选题**。

### 题目要求

1. **题干**：清晰、无歧义，长度 30-80 字。可用【】标注重点。
2. **选项**：4 个选项（A/B/C/D），其中 1 个正确答案，3 个干扰项。干扰项需有迷惑性但不能模棱两可。
3. **答案**：标注正确选项字母（如 `C`）。
4. **解析**：50 字以上，引用官方规则来源（如"参见：角色能力-XX"或"参见：重要细节-XX"）。
5. **分类**：从以下 5 类中选择：游戏机制 / 角色能力 / 能力互动 / 角色相克 / 特殊情况
6. **难度**：easy（基础）、normal（常见场景）、hard（边缘情况/复杂互动）
7. **标签**：2-5 个关键词（角色名、机制名等）

### 格式要求（JSON）

每道题格式如下：

```json
{
  "id": <全局唯一数字ID>,
  "type": "single",
  "category": "<分类>",
  "difficulty": "<难度>",
  "question": "<题干>",
  "options": ["A. <选项A>", "B. <选项B>", "C. <选项C>", "D. <选项D>"],
  "answer": "<正确选项字母>",
  "explanation": "<解析内容>",
  "tags": ["标签1", "标签2"]
}
```

### 注意事项

- 确保 4 个选项只有一个正确，不能有"以上都对/都不对"的选项
- 干扰项应与正确答案同类型/同长度，增加迷惑性
- 解析要引用具体规则来源，不要泛泛而谈
- 难度分布：easy 3题，normal 5题，hard 2题
- 分类分布均衡

### 输出格式

输出一个 JSON 数组，不要额外的说明文字。

## 示例（以洗衣妇为例）

```json
[
  {
    "id": 101,
    "type": "single",
    "category": "角色能力",
    "difficulty": "normal",
    "question": "以下哪种情况下，洗衣妇【不能】在夜晚获得信息？",
    "options": [
      "A. 被毒者毒死",
      "B. 被处决",
      "C. 被僵尸（外来者）杀死",
      "D. 被活埋"
    ],
    "answer": "C",
    "explanation": "洗衣妇每晚可得知一名善良玩家的信息。但若洗衣妇被僵尸（外来者）杀死，她整夜失去能力，无法获得信息。参见：重要细节-死亡与能力。",
    "tags": ["洗衣妇", "外来者", "僵尸", "死亡"]
  }
]
```
