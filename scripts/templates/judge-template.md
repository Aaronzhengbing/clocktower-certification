# 染钟楼谜团 判断题生成模板

## 使用说明

请将以下 Prompt 复制给 AI，提供对应的规则/角色文档片段，让它生成判断题。

---

## Prompt

你是一名《染·钟楼谜团》（Onetown Murder Mystery）的说书人认证考试出题专家。请基于以下规则/角色文档，生成 **15 道高质量的判断题**。

### 题目要求

1. **题干**：清晰、无歧义，是一个可以明确判断正误的陈述句，长度 20-60 字。可用【】标注重点。
2. **选项**：固定 2 个选项 — "是"（正确）和 "否"（错误）。
3. **答案**：`true`（题干正确）或 `false`（题干错误）。
4. **解析**：50 字以上，引用官方规则来源（如"参见：角色能力-XX"或"参见：重要细节-XX"）。
5. **分类**：从以下 5 类中选择：游戏机制 / 角色能力 / 能力互动 / 角色相克 / 特殊情况
6. **难度**：easy（基础）、normal（常见场景）、hard（边缘情况/复杂互动）
7. **标签**：2-5 个关键词（角色名、机制名等）

### 格式要求（JSON）

每道题格式如下：

```json
{
  "id": <全局唯一数字ID>,
  "type": "judge",
  "category": "<分类>",
  "difficulty": "<难度>",
  "question": "<判断题干>",
  "options": ["是", "否"],
  "answer": "true 或 false",
  "explanation": "<解析内容>",
  "tags": ["标签1", "标签2"]
}
```

### 注意事项

- 题干必须是一个明确的陈述句，不能是疑问句
- 判断题应有一定迷惑性，不要过于明显的常识题
- 解析要引用具体规则来源，说清楚为什么正确/错误
- 难度分布：easy 4题，normal 8题，hard 3题
- 分类分布均衡
- `answer` 字段使用 `true` 或 `false`（不是 "是" 或 "否"）

### 输出格式

输出一个 JSON 数组，不要额外的说明文字。
